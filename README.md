💊 MediCare Reminder

Live demo: https://medicare-assistant.ai.studio

MediCare Reminder is a responsive healthcare utility web application that helps users manage medicine schedules and perform basic dosage calculations.

✨ Features

- 💊 Add, edit, and delete medicine reminders
- ⏰ Set medicine dosage, frequency, and reminder time
- ✅ Mark medicines as Taken or Missed
- 🧮 Basic and weight-based dosage calculations
- 📋 View medicine history
- 🔍 Search medicines
- 🌙 Dark/Light mode
- 💾 Save data using browser LocalStorage
- 📱 Responsive design for mobile and desktop

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Browser Notifications API

🚀 How to Run

1. Download or clone the project.
2. Open "index.html" in a web browser.
3. For the best experience, use VS Code with Live Server.

⚠️ Medical Disclaimer

This application is for educational and calculation assistance only. It does not prescribe medicines or provide medical advice. Always verify medication dosage with a qualified doctor or pharmacist.

🎯 Objective

The goal of this project is to demonstrate how web technologies can be used to create a simple and useful healthcare-support application for medication reminders and basic dosage calculations.
